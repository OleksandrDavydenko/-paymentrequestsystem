API для обробки 1С «Платіжки із заявок PayDesk»

Бухгалтер у 1С відкриває обробку, бачить заявки «До оплати», позначає потрібні й натискає «Створити платіжки». Обробка створює в 1С чернетки платіжних доручень (у призначенні — #номер заявки, тож звірка з платежами потім сама закриє заявку) і повідомляє PayDesk номер документа. У картці заявки з'являється «Платіжку створено в 1С № …». PayDesk у 1С нічого не пише — 1С сама звертається сюди по HTTPS.

Що вміє API
  • GET /api/1c/v1/ping — перевірка зв'язку й ключа
  • GET /api/1c/v1/payment-orders?state=new&form=bank — заявки «До оплати», для яких ще немає платіжки (state: new · created · failed · cancelled · all)
  • GET /api/1c/v1/payment-orders/<id> — одна заявка
  • POST …/<id>/created — 1С створила платіжку (номер, дата, GUID документа)
  • POST …/<id>/failed — 1С не змогла створити (текст помилки бачить бухгалтер у картці)
  • POST …/<id>/reset — платіжку в 1С видалили, заявка знову «нова»

Ключ — у заголовку X-Api-Key. Повний опис полів — README PayDesk, розділ «API для 1С». У тестовому режимі API віддає демо-заявки — зручно перевіряти обробку на копії бази 1С.
